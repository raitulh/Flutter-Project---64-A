# Flutter Project - 64-A

A modern, responsive, dependency-free Flutter Task Management Application built with Material 3.

## Features

- **Custom App Bar**: Clean Material 3 top app bar featuring task title, interactive notifications, profile quick-access, and task management actions.
- **Notification Icon & Center**:
  - Interactive notification icon in the App Bar with real-time unread badge counter.
  - Interactive bottom sheet displaying task alerts, daily reminders, and system announcements.
  - Support for marking notifications as read, clearing all notifications, or swiping to dismiss individual alerts.
- **Profile Icon & Overview**:
  - Profile avatar with user initials in the App Bar.
  - Detailed profile bottom sheet displaying user credentials (e.g., student name, email, section).
  - Live task statistics overview (Total tasks, Active tasks, Completed tasks, and completion percentage).
- **Task Management**:
  - Create, view, filter (All, Active, Done), and toggle task completion.
  - Swipe to delete with SnackBar undo option.
  - Task progress indicator and summary header card.
  - Local JSON storage persistence.

## Getting Started

Run the test suite:
```bash
flutter test
```

Run the application:
```bash
flutter run
```
